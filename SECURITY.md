# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials or sensitive data in a public issue.

Contact the repository owner privately through the contact information on the GitHub profile and include:

- the affected component;
- steps to reproduce;
- potential impact; and
- any suggested mitigation.

Please allow reasonable time for investigation before public disclosure.

## Scope and deployment warning

This repository is a reference implementation using fictional synthetic data. It has not completed an independent production security assessment. Production deployment requires secret management, infrastructure hardening, monitoring, dependency review and organisational data-governance approval.
