# Contributing

Contributions that improve explainability, test coverage, accessibility, security or maintainability are welcome.

## Requirements

1. Use only synthetic or anonymised fictional data.
2. Never include credentials, tokens, private URLs or employer/customer information.
3. Add or update tests for behavioural changes.
4. Keep financial calculations deterministic and auditable.
5. Explain any AI-generated output's grounding and fallback behaviour.
6. Use clear commit messages describing the intent of the change.

Security reports must follow [SECURITY.md](SECURITY.md) and must not be filed publicly.
